# Звуки FastFood

База: `Assets/Audio/FastFood/`. Исходники находятся во внешней `C:\Users\moroz\Desktop\SoundDatabase`; при импорте они не менялись.

| Папка | Содержимое | Подключение |
| --- | --- | --- |
| `Ambience` | `fastfood_amb_room_tone_01.ogg`, 4 минуты | Фон всего уровня, плавное включение через существующие `SceneStarter` и `AudioController`; зацикленное потоковое воспроизведение |
| `Movement` | `fastfood_sfx_player_walk_01–03.wav` | События шагов анимаций ходьбы и приседания |
| `Movement` | `fastfood_sfx_player_run_01–03.wav` | События шагов при беге с Shift |
| `Movement` | `fastfood_sfx_player_jump_01–03.wav` | Событие анимации прыжка |
| `Interactions` | `fastfood_sfx_item_pickup_01.mp3` | Назначен существующему callback `AudioMovement.PlayIntreractionSound` для анимации Reach; отдельной механики подбора на этом уровне пока нет |
| `Kitchen` | Холодильник, фритюр, стекло, жарка мяса, сигнал/дверца/огонь духовки, солонка, газировка, слив воды | Импортированы для будущих механик; автоматически не проигрываются |

Всего 21 AudioClip из 15 записей: для ходьбы, бега и прыжка выделено по три коротких варианта. Они выбираются случайно в момент события анимации. Остальные MP3 скопированы целиком, из двух MP4 извлечены аудиодорожки в WAV. Полные исходные серии шагов и прыжков остаются во внешней базе.

В сцене у `AudioController` поле `_volume` задаёт целевую громкость фона (0.22), у `Player/AudioMovement` поле `_volume` — громкость действий (0.5). Для шагов ходьбы, приседания и бега дополнительно применяется `_footstepVolumeMultiplier = 0.18`: итоговый коэффициент 0.09, на 14.9 дБ тише прежнего. Уровень выбран по сравнению с записями шагов NightField; прыжки и взаимодействия сохраняют громкость 0.5. В остальных сценах множитель по умолчанию равен 1. Все звуки подчиняются общей громкости `GameSettings`. На источниках используется 2D-звук, чтобы расстояние до камеры не меняло громкость при переходе на кухню.

`FastFoodAudioPause` на `AudioController` при `Time.timeScale = 0` приостанавливает фон и источник игрока, затем продолжает с прежней позиции. Источник меню не затрагивается. События шагов игнорируются при паузе, смерти, блокировке ввода, отсутствии движения и в воздухе. Новые поля `AudioMovement` необязательны: существующие назначения других сцен и префабов сохранены.

Подготовка записей воспроизводится скриптом `AgentScripts/PrepareFastFoodAudio.py --ffmpeg <путь к ffmpeg>`: он создаёт новые файлы и отказывается перезаписывать уже существующие. Точки нарезки и SHA-256 оригиналов сохранены в локальном `Logs/FastFoodAudioSession/preparation-manifest.json`.

`AgentScripts/ConfigureFastFoodAudio.cs` назначает звуки и настройки импорта через Unity Editor. Он требует открытую сохранённую FastFood вне Play Mode и сохраняет сцену после настройки аудио. Повторный запуск вернёт громкости и ссылки к значениям скрипта; для обычной ручной настройки повторный запуск не нужен.

Проверка в Play Mode: аудиосигнал фона и событий ходьбы/бега/прыжка, остановка шагов, блокировка ввода, callback взаимодействия, пауза/продолжение без сброса позиции, сохранённая общая громкость и переходы зал → кухня → зал. Проверка и результаты находятся в игнорируемой `Logs/FastFoodAudioSession/`.
