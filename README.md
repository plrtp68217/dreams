# DREAMS

![Unity](https://img.shields.io/badge/Unity_6-000000?logo=unity&logoColor=white)
![C#](https://img.shields.io/badge/C%23-512BD4?logo=dotnet&logoColor=white)
![Status](https://img.shields.io/badge/status-в_разработке-orange)

Атмосферный 2D-платформер в жанре side-scroller с пиксельной графикой. Героиня Ева преследует таинственного зайца сквозь мрачные локации, прячется от луча прожектора Глаза и узнаёт историю через записки и диалоги.

## Игровые механики

- Платформинг: бег, прыжки, ускорение
- Скрытность: укрытия, в которых можно спрятаться от врага
- Враг-наблюдатель с лучом прожектора, смерть и возрождение
- Погоня за зайцем с поведением на основе состояний
- Взаимодействие с предметами, записки и диалоговые окна
- Чекпоинты
- Локализация диалогов и интерфейса с переключением языка
- Параллакс-фон, динамическая камера, мерцающий свет, звук шагов и окружения

## Управление

| Клавиша | Действие |
|---|---|
| `A` / `D`, `←` / `→` | Движение |
| `Space` | Прыжок |
| `Shift` | Ускорение |
| `Ctrl` (удерживать) | Спрятаться в укрытии |
| `E` | Взаимодействие, закрыть записку |
| `Esc` | Меню паузы |

## Технологии

- **Unity 6** (6000.2.4f1), Universal Render Pipeline (2D)
- **C#**
- Cinemachine, Input System, 2D Animation, Tilemap, Sprite Shape
- Импорт анимаций из Aseprite

## Архитектура

```
Assets/Scripts/
├── Entities/          # Базовые сущности и интерфейсы (IDamageable)
├── Implementations/   # Игрок, заяц, враг: контроллеры, сенсоры, состояния
├── Services/          # Ввод, движение, аудио, чекпоинты, графика
├── DialogSystem/      # Диалоги и база локализованных реплик
├── Scene/             # Управление сценами и переходами
├── Camera/            # Камера и триггеры камеры
├── UI/                # Главное меню, пауза, переключение языка
└── ...                # Укрытия, свет, аудио, визуальные эффекты
```

Логика разделена на сервисы, а поведение юнитов построено на состояниях, что упрощает добавление новых персонажей и механик.

## Запуск

1. Установите Unity Hub и Unity **6000.2.4f1**
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/plrtp68217/dreams.git
   ```
3. Откройте папку проекта через Unity Hub и запустите сцену главного меню
