- Редактор: **Unity 6000.2.4f1**, C#, URP **17.2.0**, Cinemachine **3.1.5**, uGUI/TextMeshPro, Aseprite Importer **2.0.1**.
- Рабочая папка этой машины: `C:\Users\moroz\Desktop\DEV\UNITY\DREAMS`. Оболочка — PowerShell.
- Репозиторий: `https://github.com/plrtp68217/dreams.git`.
- Сцены: `Assets/Scenes/Intro.unity`, `MainMenu.unity`, `NightField.unity`, `FastFood.unity`.
- В текущей `main` общий список сцен сборки: Intro (0), MainMenu (1), NightField (2). Сборка запускается со вступления, затем открывается меню. Аргумент кнопки «Играть» обновлён на 2, она запускает NightField. Возврат из паузы загружает MainMenu по имени и не повторяет вступление. FastFood открывается отдельно в Editor и запускается через Play. При изменении маршрутов учитывай `EditorBuildSettings.asset`, `SceneName` и загрузку по индексу.

## Код и ресурсы

- `Assets/Scripts/Services/`: ввод, движение, звук, чекпоинты, `GameSettings`.
- `Implementations/`: игрок, заяц, Глаз и NPC. `Entities/AEntity` хранит состояние жизни/укрытия и событие смерти; компоненты кешируются в `Start`, не в `Awake`.
- `DialogSystem/`: диалоги и взаимодействия. `LocalizedDialogueSystem` — singleton с `DontDestroyOnLoad`, JSON `Assets/Resources/dialogues.json`, языки Russian/English, событие `LanguageChanged`.
- `Till/`: `TillTrigger`, `GuestOrderSequence`, `FastFoodKitchenRoute`, `FastFoodKitchenDoor`.
- `Camera/`: контроллеры камеры, триггеры и `FastFoodCameraHorizon`.
- `UI/`: меню, пауза, настройки, `TypewriterText`, чек и курсор. `Light/`: мерцание света.
- Основной ввод в `main` идёт через `InputService` и legacy `Input.GetKey*`. Установленный пакет Input System не означает, что весь геймплей использует его.
- Ссылки на компоненты задаются через `[SerializeField]` в сценах/префабах. При переименовании полей сохраняй сериализацию через `[FormerlySerializedAs]`. Параметры Animator должны совпадать с именами соответствующих enum.
- Сохраняй Unity `.meta` и GUID. Новые текстовые файлы — UTF-8. В старых скриптах встречается Windows-1251 (например, `Player.cs`, `InputService.cs`); не порть кириллицу массовой перекодировкой.
- Общий префаб камеры и паузы: `Assets/Prefabs/CAMERA.prefab`; правка затрагивает несколько сцен.
- `AgentScripts/` содержит вспомогательные скрипты построения сцен. Они меняют и сохраняют сцену: не запускай их для простого просмотра или без проверки текущих ручных настроек.

## Что реализовано в FastFood

### Касса, кухня и камера

- Слева от кассы есть невидимая граница, чтобы Ева не уходила далеко за экран.
- После первого заказа от мужчины без лица и выхода из кассы появляется подсказка идти налево. Левый проход ведёт на кухню; правый край кухни возвращает к кассе. Заказ сохраняется, переходы повторяемые.
- Кухня — отдельная область той же сцены, примерно в центре X = −20; новая сцена не загружается.
- Используются существующий `CAMERA/Confiner` для зала и `CAMERA/KitchenConfiner` для кухни. На кухне камера следует по горизонтали, поскольку фон шире экрана.
- `FastFoodCameraHorizon` фиксирует высоту камеры, чтобы после возврата фон не смещался вверх и не открывал синий цвет очистки.
- Переходы: плавное затемнение/проявление по 0.4 с, удержание чёрного 0.1 с. Камера переводится и обновляется под затемнением: в первом видимом кадре Ева уже находится на экране с обеих сторон перехода.

### Чек, курсор и настройки

- Использован спрайт чека из внешней базы арта. `GuestOrderSequence` показывает полученный заказ и обновляет текст по `LanguageChanged`, даже если чек уже открыт.
- `ReceiptHover`: чек сначала развёрнут 5 с, затем уменьшается до 0.55 масштаба; наведение плавно раскрывает его с небольшим overshoot, уход курсора снова сворачивает. Длительность анимации — 0.35 с.
- Курсор должен быть виден **всегда**, включая обычный геймплей и закрытие паузы. Не возвращай старое скрытие курсора.
- `Esc`: пауза с заголовком DREAMS, продолжение, настройки, выход в главное меню. Из настроек Esc возвращает на страницу паузы.
- `GameSettings`: общая громкость, яркость 50–150%, RU/EN, полный экран, сброс; сохранение в PlayerPrefs. Яркость применяется через runtime URP Volume.
- Прозрачность затемнения одинакова на страницах паузы и настроек (alpha 0.78). Закрытие паузы восстанавливает прежнюю блокировку ввода, в том числе во время кассы/катсцены.

### Администратор

- После пробуждения Евы администратор подходит, произносит вступительные реплики и ждёт, пока Ева не встанет за кассу.
- Последняя явная правка пользователя: скорость администратора **0.6**, как раньше. При начале инструктажа у кассы он сначала телепортируется в прежнюю точку появления и затем идёт к кассе. Не заменяй это непрерывным подходом от Евы.
- Связанные файлы: `NpcVisit`, `SceneIntro`, `AgentScripts/ConfigureFastFoodAdminIntro.cs`; для инструктажа `_continueFromCurrentPosition = false`.

На земле стоя при смене направления проигрывается разворот с сохранением движения, затем продолжается ходьба/бег/ожидание. **По последней правке пользователя, при Ctrl (сидение/приседание) направление меняется мгновенно, без анимации стоя; отдельную анимацию сидя добавят позже.** Нажатие Ctrl во время разворота сразу возвращает сидящую/присевшую позу. В прыжке направление также меняется сразу, сохраняя воздушную анимацию.
- **Последняя настройка скорости:** по просьбе сделать разворот естественнее общая скорость увеличена вдвое (`_turnSpeed = 2`). Обычная анимация теперь рассчитана на 0.15 с вместо 0.3 с. При быстрых сменах направления применяется дополнительный множитель 3 (`_rapidTurnSpeed = 3`, окно `_rapidTurnWindow = 0.35` с), то есть скорость 6 и расчётная длительность 0.05 с. При смене направления во время разворота он отражается и продолжается из соответствующей текущей позы к новой цели, без очереди полных анимаций. Параметр `AnimatorFloat.TurnSpeed` управляет скоростью только состояния `Turn`, остальные анимации не ускоряются. Пауза останавливает текущий кадр; переходы кухни и блокировки отменяют разворот без перезаписи направления, выбранного маршрутом.

Без компонента `PlayerTurnAnimation` работает прежний мгновенный flip.
- Настройщик: `AgentScripts/ConfigureFastFoodTurn.cs`. Он режет спрайт через Sprite Editor Data Provider с проверками возможностей, создаёт клип/контроллер и сохраняет сцену после назначения компонента.
