- Редактор: **Unity 6000.2.4f1**, C#, URP **17.2.0**, Cinemachine **3.1.5**, uGUI/TextMeshPro, Aseprite Importer **2.0.1**.
- Рабочая папка этой машины: `C:\Users\moroz\Desktop\DEV\UNITY\DREAMS`. Оболочка — PowerShell.
- Репозиторий: `https://github.com/plrtp68217/dreams.git`.
- Сцены: `Assets/Scenes/Intro.unity`, `MainMenu.unity`, `NightField.unity`, `FastFood.unity`.
- В текущей `main` общий список сцен сборки: Intro (0), MainMenu (1), NightField (2). Сборка запускается со вступления, затем открывается меню. Аргумент кнопки «Играть» обновлён на 2, она запускает NightField. Возврат из паузы загружает MainMenu по имени и не повторяет вступление. FastFood открывается отдельно в Editor и запускается через Play. При изменении маршрутов учитывай `EditorBuildSettings.asset`, `SceneName` и загрузку по индексу.

## Код и ресурсы

- `Assets/Scripts/Services/`: ввод, движение, звук, чекпоинты, `GameSettings`.
- `Implementations/`: игрок, заяц, Глаз и NPC. `Entities/AEntity` хранит состояние жизни/укрытия и событие смерти; компоненты кешируются в `Start`, не в `Awake`.
- `DialogSystem/`: диалоги и взаимодействия. `LocalizedDialogueSystem` — singleton с `DontDestroyOnLoad`, JSON `Assets/Resources/dialogues.json`, языки Russian/English, событие `LanguageChanged`.
- `Till/`: `TillTrigger`, `GuestOrderSequence`, `FastFoodKitchenRoute`, `FastFoodKitchenDoor`.
- `Camera/`: контроллеры камеры, триггеры и `FastFoodCameraHorizon`.
- `UI/`: меню, пауза, настройки, `TypewriterText`, чек и курсор. `Light/`: мерцание света.
- Основной ввод в `main` идёт через `InputService` и legacy `Input.GetKey*`. Установленный пакет Input System не означает, что весь геймплей использует его.
- Ссылки на компоненты задаются через `[SerializeField]` в сценах/префабах. При переименовании полей сохраняй сериализацию через `[FormerlySerializedAs]`. Параметры Animator должны совпадать с именами соответствующих enum.
- Сохраняй Unity `.meta` и GUID. Новые текстовые файлы — UTF-8. В старых скриптах встречается Windows-1251 (например, `Player.cs`, `InputService.cs`); не порть кириллицу массовой перекодировкой.
- Общий префаб камеры и паузы: `Assets/Prefabs/CAMERA.prefab`; правка затрагивает несколько сцен.
- `AgentScripts/` содержит вспомогательные скрипты построения сцен. Они меняют и сохраняют сцену: не запускай их для простого просмотра или без проверки текущих ручных настроек.
